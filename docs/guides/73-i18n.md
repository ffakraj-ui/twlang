# Internationalization (i18n)

## Translation Files

`[home]/data/translations/en.json`:
```json
{
    "home.title": "Welcome",
    "nav.about": "About"
}
```

`[home]/data/translations/hi.json`:
```json
{
    "home.title": "Swagat hai",
    "nav.about": "Hamare bare mein"
}
```

## Loading Translations

```tw
let lang = "en"
load "@./data/translations/en.json"

body {
    h1 "{home.title}"
    a "{nav.about}" { href "/about" }
}
```

## Language Switching

```tw
select {
    on:change "switchLang()"
    option "English" { value "en" }
    option "Hindi" { value "hi" }
}

script {
    function switchLang() {
        window.location.href = '/' + event.target.value
    }
}
```

## URL-Based Language

```
[home]/pages/
├── en/
│   ├── index.tw      -> /en
│   └── about.tw      -> /en/about
├── hi/
│   ├── index.tw      -> /hi
│   └── about.tw      -> /hi/about
└── index.tw           -> / (default)
```
