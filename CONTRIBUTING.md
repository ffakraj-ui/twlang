# TW Framework — Contributing

## Development Setup

```bash
git clone https://github.com/ffakraj-ui/twlang.git
cd twlang/twlang-main-v2/twlang-main
pip install -e .
pip install tw-framework[dev]
pytest
```

## Running Tests

```bash
pytest
pytest tests/test_stability.py -v
pytest tests/test_stability_core.py -v
```

## Submitting Changes

1. Fork the repository
2. Create a feature branch
3. Make changes, add tests
4. Run `pytest` to verify
5. Submit a pull request
