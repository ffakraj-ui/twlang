0. WHAT TW IS (AND IS NOT)
================================================================================

TW ("TW Framework", package name `tw-framework`, PyPI) is a custom language +
framework in one package. It is NOT React, NOT Vue, NOT Svelte, and NOT
TypeScript, although it borrows ideas from each. It CAN use React alongside
its own VDOM via the React compatibility layer.

- Language: `.tw` files (markup + page logic) and `.tss` files (styles) compile
  to plain HTML, CSS, and JS. TW has its own lexer, parser, and compiler
  pipeline written in Python.
- Framework: file-based App Router routing, `.twm` API routes, middleware,
  dev server, NPM package manager, React compatibility, esbuild bundling.
- Package: `pip install tw-framework` (Python). NPM packages via `tw install`.
- Project root marker: `tw.config` file.
- Source folder: `[home]/` (literal brackets — App Router root).

================================================================================
1. SYNTAX — .tw FILES
================================================================================

TW uses block-based syntax with curly braces. NOT JSX. NOT HTML angle brackets.

### 1.1 Page Block
```tw
page {
    title "My Page"
    render static
}
```

### 1.2 Render Modes
- `render static` — SSG, build-time HTML (default)
- `render server` — SSR, per-request server render
- `render edge` — edge runtime
- `render interactive` — React client-side hydration
- `render dynamic` — auto-detect (state/for/if → server, else static)

### 1.3 Body
```tw
body {
    h1 "Hello World"
    p "This is a paragraph."
    div { class "card"
        h2 "Title"
        p "Content"
    }
    a "Click me" { href "/about", class "link" }
}
```

### 1.4 Text Interpolation
```tw
h1 "Hello {name}"
p "Count: {count}"
a { href "/blog/{post.slug}" text "Read more" }
```

### 1.5 State Management
```tw
state {
    count 0
    name "Guest"
}

body {
    h1 "Count: {count}"
    button {
        on:click "__tw.set('count', __tw.get('count') + 1)"
        text "+"
    }
}
```

### 1.6 Conditional Rendering
```tw
if isLoggedIn {
    h1 "Welcome back!"
}
else {
    h1 "Please log in"
}
```

### 1.7 Loops
```tw
each posts as post {
    div { class "card"
        h2 "{post.title}"
        p "{post.excerpt}"
    }
}
```

2. IMPORTS
================================================================================

TW supports TWO import syntaxes:

### 2.1 Component Import
```tw
import "Navbar"
import "Button"
```
Loads `.tw` files from `[home]/components/`. Use as tags:
```tw
body {
    Navbar {}
    Button { href "/about", label "Click" }
}
```

### 2.2 ES6 Library Import (v0.8.47+)
```tw
import { startCountdown } from "@/lib/countdown"
import { formatData, parseJSON } from "@/lib/utils"
```
Loads `.js`/`.ts`/`.mjs` files from `[home]/lib/`. Use in script:
```tw
body {
    div { id "countdown" }
    script { startCountdown() }
}
```

### 2.3 Load Directive
```tw
load "@/blog/posts.json"        # JSON data (key = filename)
load "@/style.tss"               # stylesheet
load "@/lib/auth"                # .twm server module
```

### 2.4 Script Blocks
- Inline: `script { console.log("hello") }` — raw JS
- {prop} interpolation in scripts (v0.8.47+): `script { new Date("{target}") }`
- External: `script { src "@/lib/file.js" }` — @/ resolved to /_tw/scripts/ (v0.8.47+)
- External URL: `script { src "https://cdn.example.com/lib.js" }`

================================================================================
3. COMPONENTS
================================================================================

### 3.1 Creating Components
File: `[home]/components/Button.tw`
```tw
let label "Click"
let href "#"

a { class "btn", href "{href}"
    text "{label}"
}
```
No wrapper needed — file IS the component. `let` defines props.

### 3.2 Auto-Discovery (v0.8.43+)
Components in `[home]/components/` are auto-discovered. No `import` needed:
```tw
body {
    Button { href "/about", label "Get Started" }
}
```
`import "Button"` also works but is optional.

### 3.3 Scoped CSS (v0.8.37+)
File: `[home]/components/Button.tss`
```tss
btn-primary {
    background blue
    color white
}
```
Auto-scoped via `data-tw-{hash}`. `@media` preserved. `@keyframes` global.

4. LAYOUTS
================================================================================

File: `[home]/layout.tw`
```tw
page {
    title "My Site"
    render static
}

load "@/style.tss"

head {
    meta { charset "utf-8" }
    meta { name "viewport", content "width=device-width, initial-scale=1" }
    seo {
        description "Site description"
    }
}

body {
    Navbar {}
    main { class "main-content"
        children
    }
    Footer {}
}
```

`children` keyword injects page content.

5. DYNAMIC ROUTES
================================================================================

```
[home]/blog/[slug]/page.tw    # route: /blog/:slug
[home]/blog/posts.json        # data
```

```tw
page {
    title "{title}"
    render static
    generateStaticParams "posts.json"
}

body {
    h1 "{title}"
    p "{excerpt}"
}
```

JSON: `[{"slug": "post-1", "title": "First", "excerpt": "..."}]`

================================================================================
6. TSS STYLESHEETS
================================================================================

```tss
body {
    margin 0
    font-family system-ui, sans-serif
    background var(--bg)
}

:root {
    --bg #ffffff
    --fg #0b1220
}

.btn {
    padding 14 32
    border-radius 12
    background var(--accent)
}
```

Space-separated values. Numbers without units get `px`.

================================================================================
7. API ROUTES (.twm)
================================================================================

File: `[home]/api/users/route.tw`
```tw
fn get(request) {
    return {
        status: 200,
        json: [{ id: 1, name: "Ada" }]
    };
}

fn post(request) {
    return {
        status: 201,
        json: { ok: true }
    };
}
```

Server-only. Not in dist/. Methods: get, post, put, patch, delete, options.

8. tw.config OPTIONS
================================================================================

```
name: My TW Site
site_url: https://example.com
description: Site description
theme: system
pretty_urls: true
search: true
modular_pipeline: true
allow_raw_script: true
sitemap: true
robots: true
rss: true
auto_image_alt: true
```

### 8.1 Sitemap/Robots/RSS (v0.8.42+)
All opt-in (default OFF). Developer file > auto-generated.
Place custom files in `public/` to override.

### 8.2 XSL Sitemap (v0.8.42+)
Auto-generated `sitemap.xsl` for stylish sitemap display.
Custom: `public/sitemap.xsl`.

### 8.3 Auto Image Alt (v0.8.42+)
Filename → alt text (first 8 chars).

================================================================================
10. BUILD FEATURES
================================================================================

- Zero JS by default (HTML + CSS only)
- Code splitting (shared chunks)
- Incremental build (v0.8.37+ — modified files only)
- Error overlay (v0.8.37+ — dev server shows styled errors)
- Tree shaking (detects inline component usage)
- Dev server auto-reload (SSE)
- NPM support (tw install)
- esbuild bundling
- React compatibility (render interactive)

================================================================================
12. WHAT TW IS NOT
================================================================================

- NOT React (no JSX, no function Page(), no useState)
- NOT Next.js (no export default, no getStaticProps)
- NOT Vue (no <template>, no v-if)
- Own syntax: page { }, body { }, state { }, each ... as ... { }
- CAN use React via render interactive + tw install react react-dom
